# ![](https://monologue.page/assets/Monologue-icon.svg)  Monologue
A private, local, chronological personal microblog style journal app.

<hr>

Monologue is built as a website and a PWA(Packaged Web Application), it has also been wrapped in a TWA(Trusted Web Application) for distribution on android.

I made Monologue because - like many - I don't like any other note taking apps, so - like many - I made my own.
